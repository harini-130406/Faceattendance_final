Excel Column Format Guide

Your Excel sheet columns can be in any order, with matching headers:

  • Registration ID Required
  • First Name
  • Last Name
  • Branch (e.g. CSE, IT, ECE)
  • Year (e.g. 1, 2, 3, 4)
  • Section (e.g. A, B, C)
  • Email
  • Phone
  • Google Drive Photo Link (Per-student Drive image link)
